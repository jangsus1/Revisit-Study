# Cluster Flow Stimulus Gallery

This study is not a study: it is a reviewer page for the stimuli used by the
**cluster-flow staircase** experiment.

The next page shows, for one seed, all six grouping cues. Each row puts the grouped
**stimulus A** (24 dots in 6 clusters, wired into a directed flow) next to the ungrouped
**stimulus B** baseline at the same canvas size, so the two can be compared directly.

- **Seed** picks the display; the same seed always produces exactly the same pair.
- **N_B** sets the number of dots in the baseline (the staircase varies this between 8 and 48).
- **sparse / dense** switches the extra within-cluster arrows and the backbone skip links on.

The footer under each panel prints the generator diagnostics: the seed, how many derived seeds
were needed before the display satisfied the occlusion invariants, the cluster sizes, the jitter
amplitude, the horizontal and vertical gaps, and the cluster traversal order.
