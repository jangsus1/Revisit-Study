# Help

- A white cross means the next pair of diagrams is about to appear.
- Press **i** if the **first** diagram had more items, **j** if the **second** did.
- Count the dots, not the groups and not the arrows.
- The two diagrams never have the same number of items, so always answer, even if you are guessing.
- If you leave fullscreen, a button appears asking you to return to it. Click it and the trial
  continues.
- Questions or problems? Contact **contact@revisit.dev**.
